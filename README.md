**Check existing reports first:** [Open issues](https://github.com/Divetek-Inc/intellij-sfcc-vscode/issues) · [All issues, including closed](https://github.com/Divetek-Inc/intellij-sfcc-vscode/issues?q=is%3Aissue)

If your issue already exists, add useful details or a 👍 reaction to the existing report. Open a separate issue for each distinct problem or idea.

### What to include

| Bug report | Feature request |
| --- | --- |
| A short, specific title. | The problem you want to solve. |
| VS Code version, Intellij SFCC extension version, and operating system. | Your current workflow and its limitations. |
| Numbered steps to reproduce the problem. | The behavior or improvement you would like. |
| What you expected and what actually happened. | A concrete example of when it would help. |
| Relevant error text, screenshots, or a small sanitized example. | Any alternatives or workarounds you have tried. |

**Issues are public.** Remove passwords, tokens, license keys, customer data, and other confidential information from screenshots, logs, and examples. Send account, billing, or security-sensitive questions to [support@intellijsfcc.com](mailto:support@intellijsfcc.com).
